## 2. 검정 방법 (동결)

| 대상 | 방법 |
|---|---|
| 비율 비교 (성숙 곡선, gate 비교) | Wilson CI + **단측 two-proportion** (소표본 시 Fisher exact) |
| E2 go/no-go | max_n ŝ ≥ 0.8 **AND** ŝ(80) > ŝ(10), 단측 two-proportion, α = 0.05 |
| E3 T-천장 | ŝ(80)의 T별 **단측 감소** 검정 |
| E5 비열등 (H4) | **paired bootstrap** 95 % CI, margin −3 %p |
| E5 호출률 감소 | 첫 **1,000** ep vs 끝 **1,000** ep, 단측 (4,000 스트림 비례 스케일 — §5 이력 2026-08-15) |
| seed 일관성 (E6) | **부호 일관성 + 이항 검정** (Paper 1 관행) |

**E0-5 스모크 재확인 규칙 (구 ISSUE-7 제안 — 연구원 승인 대기):**
1차 = 스위트당 10 태스크 × 1 ep (init_states[0]). 판정:
- PASS = 완결(n=10) AND |rate − pub| ≤ 0.10
- RECHECK = 완결(n=10) AND 밴드 밖 AND 실패 ≤ 2 → 해당 스위트만 **20 ep**(task당 2 init state) 재판정
- FAIL = 그 외. **중도 크래시·표본 수 불일치는 무조건 FAIL** (부분 로그 PASS 금지)
주의: 파이프라인이 결정적이므로 재확인은 반드시 추가 init state로 수행(동일 표본 재실행은 무정보).
(2026-08-15 실측: 4 스위트 전부 10/10 — 이 규칙은 미발동으로 종료. 규칙 자체는 이후 재실행 대비 유지.)

## 3. 사전등록된 예외 규칙

**E1 S_V 임계 완화 조항 (설계서 §5 / §12-2 — 연구원 승인 대기).**
스위트별 재측정 S_V가
- **≥ 0.85** → 그대로 진행
- **[0.75, 0.85)** → 해당 스위트의 임계 완화를 **본 파일 §5 변경 이력에 사유와 함께 기록한 후** 진행
- **< 0.75** → 해당 셀을 **제외하고 재설계** (셀을 줄이되 셀당 통계는 유지)

**E2 no-go 시 원인 트리 1회 반복 규칙.**
데이터 품질 / HP / 관측 구성의 원인 트리를 1회 순회하며 재시도. 재실패 시 가설 수정 보고.

**E4 관할 파일럿 미달(AUC < 0.75) 시 우아한 퇴화.**
주장 축소 = 성숙도 단독 + "관할은 열린 세계(Paper 2) 과제" 프레이밍, E5는 성숙도 단독 진행.

**E4 연산 예산 초과 시.** 셀 수를 줄이되 **셀당 통계량은 유지**한다 (역은 금지).

**보충 (2026-08-15, 지시서 v2 — clarification, 기준 변경 아님):**
- C-T3 선정 기준(S_V ≥ 0.96)이 배제한 최약 태스크 명시: libero_10 **task8** "put both moka pots
  on the stove" (E1 21/25 = 0.84). 본 기준·선정은 수집 시작 전 등재분 — 사후 문서화가 아님.
- C-T2 클러스터 ID 메커니즘: 연쇄 래퍼는 관측 지시어로 **원 태스크 문자열을 상속**하므로
  "결합 지시어 = 새 태스크 ID"는 env 타입(`chained_*`)에 의한 장부상 ID다. E5 혼합에 C-T2가
  없어 1층 지시어 정확 일치 클러스터링과 충돌 없음.
- **C-T2 수집 중단 트리거 (통합 지시서 §1-2, 연구원 승인)**: 전역 절대선 "<0.90" 폐기 —
  task5 연쇄 기대 성공률 S_V² = 0.871 < 0.90이라 정상 수집도 오탐 확률 0.79 (검증 실측).
  확정 규칙: 관측 성공률이 클러스터별 기대치 **S_V,k²** (수집 실측 기반: task0 = 0.951,
  task5 = 0.871) 대비 **단측 이항 검정 α = 0.01**로 유의 미달일 때만 중단·보고.
- **C-T2 전환 의미론 개정 (옵션 A — 연구원 판정 2026-08-15, B 기각·C 불필요)**:
  stage 전환 = 재배치 init의 전체 상태 벡터로 **완전한 에피소드 경계 프로토콜**
  (E0-6 3단: seed → reset → set_init_state → settle; 전환 seed = 에피소드 seed, 결정적).
  의미론 = "재발 조우 연속의 압축"(스트림 에피소드 경계와 동형) — **로봇 포즈 연속성
  단절을 명시**한다. 근거: teacher(OFT)는 홈 포즈 시작 분포로만 학습되어 stage 1 종료
  포즈에서 재시작이 관할 밖(v1 래퍼 스모크 0/10 동결, 통제 실험 홈 포즈 153스텝 성공 —
  `results/e3/t2_diag*.json`, `t2_smoke_v1_negative.json`). 상대 트리거 기대치(S_V,k²)는 불변.
  **메커니즘 정밀화 (v3, 의미론 불변 — §5 이력)**: 최초 구현(v2: set_init_state + settle만)은
  reset 생략으로 OSC 컨트롤러 상태가 이월되어 settle 후 로봇이 홈에서 최대 0.48 rad 이탈
  (물체 Δ=0.0; `t2_diag4.json`) — task5의 유사 물체 오인 절벽에서 stage 2 계통 실패(0/9,
  `t2_smoke_v2_negative`). E0-6이 재현 프로토콜을 3단으로 강제한 그 사유가 전환에도 적용됨을
  실측 확인 → v3 = begin_episode 재사용으로 stage 2 시작이 fresh 에피소드와 구성적 동등
  (task5 fresh 통제 118스텝 성공, v3 probe 2/3 — 잔여 실패는 확률적 범위). 이에 따라
  **S_V,k² 기대치의 근거(§4e 주석)가 정확히 성립**한다. v2로 수집된 task0 연쇄 120 ep는
  폐기·재수집 (BC 데이터와 런타임 프로세스 일치).
- **C-T2 주 검정 개정**: ŝ_chain(80) vs **곱 기준선 (ŝ_T1(80))²** — 단측 이항 검정
  (p₀ = 곱 추정치, α = 0.05) + Wilson CI 병행. **하회** = 전환 의미론 하에서도 장기 시퀀스
  학습의 결합 비용 존재 / **상회** = "실질 시연 2배" 효과가 후보 설명 (사전 등재 — 사후
  선택 아님). 원 기준(ŝ(80)의 T별 단측 감소, §2)은 **병행 보고**로 유지.
- **C-T2 held-out 확대 (연구원 승인 2026-08-15 — 결과 판독 전 등재)**: chained 2클러스터의

  불변, **병합 전 20개 중간 수치는 비보고** — 비맹검 유지). 이에 따라 주 검정의 T1 기준은
  **E2 50-ep 곡선의 ŝ_T1(80)** (task0·task5 공히 48/50 = 0.96 → p₀ = 0.9216). p₀가 추정치인
  불확실성 보완으로 **모수 부트스트랩 비교 병행 보고** (B = 10,000, seed 0:
  ŝ₁* ~ Bin(50, ŝ₁)/50, ŝ_chain* ~ Bin(50, ŝ_chain)/50, Δ* = ŝ_chain* − (ŝ₁*)² —
  P(Δ*<0)·95% CI 보고).
