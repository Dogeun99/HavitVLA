## 4. 부적격(X) 클러스터 사후 분석 — **탐색적** (§5 2026-08-17 등재)

후반 VLA 호출의 **72.2%**가 부적격 10개 클러스터에서 발생한다. 추가 rollout 없이 로그만으로 산출했다.

- **규칙 1**: 10/10개가 부적격 확정 후에도 BC 풀이 마지막 grid(80)를 넘겨 축적됐다 (중앙 잉여 **+59**) — 재도전 규칙이 있었다면 재학습 자격이 있었을 클러스터 수.
- **규칙 2**: E3 배치에서 N*≤80이던 클러스터 **9/10개**가 스트림에서는 부적격이 됐다 → 배치·스트림 형성 조건 차이가 실재한다.

### 원인 규명 (사후 진단)

**발견 ① 성숙 문턱의 이름 충돌.** E3 성숙은 점추정 `ŝ≥0.8`이고 E5 성숙은 `Pr(s≥0.8|D)≥0.9`다. P=20에서 후자는 **19/20 (=0.95)**를 요구한다 — 같은 τ를 쓰지만 실질 문턱이 0.80 대 0.95로 다르다.

**발견 ② 라운드2 이월 함정.** c=0.25 재초기화가 라운드1 실패를 φ로 승계하므로, **라운드1 실패가 9회 이상이면 라운드2에서 20/20 만점을 받아도 Pr<0.9**다. 즉 라운드2 시작 시점에 X가 이미 확정돼 있다. 해당 **5/10개**이며, 그중 `libero_object_task5`는 **실제로 라운드2 만점(20/20)을 받고 탈락**했다(E3 ŝ(80)=1.0).

| 클러스터 | E3 ŝ(80) | 스트림 probe r1 → r2 | 라운드2 사전 확정 |
|---|---|---|---|
| object_task5 | 1.0 | 11/20 → 20/20 | **예** |
| object_task8 | 0.95 | 15/20 → 19/20 | 아니오 |
| goal_task0 | 0.85 | 14/20 → 18/20 | 아니오 |
| goal_task5 | 0.95 | 18/20 → 17/20 | 아니오 |
| goal_task6 | 1.0 | 11/20 → 18/20 | **예** |
| object_task1 | 0.75 | 13/20 → 18/20 | 아니오 |
| goal_task9 | 1.0 | 15/20 → 17/20 | 아니오 |
| object_task9 | 0.9 | 11/20 → 17/20 | **예** |
| 10_task0 | 0.75 | 4/20 → 14/20 | **예** |
| object_task0 | 0.95 | 7/20 → 14/20 | **예** |

**형성 부진과 판정 탈락은 구분된다**: object_task5·task8은 스트림 probe 성적이 E3 held-out과 같은 수준(1.0 / 0.95)인데 판정 규칙에서 탈락했고, object_task0·10_task0은 형성 자체가 부진했다(0.7 대 E3 0.95 / 0.75).

## 5. 배치·스트림 형성 간극 진단 — **구현 결함 확정** (§5 2026-08-17, 갱신 판독 2)

판독 규칙 2-(c)가 발동했다: **불일치 — 구현 결함 확정 (연구원 회부)**

**기전.** `habits/train.py`는 정규화 통계를 `compute_stats(episodes[:max(n_grid)])`로 산출한다. E3는 `--n-grid 10 20 40 80`(일괄)이라 max=80 풀에서 **1회 산출 후 전 단계 동결**되지만, E5 lazy 재학습은 `--n-grid {n}` 단일값이라 **n=20은 20개 풀, n=80은 80개 풀**에서 각각 산출된다. 즉 warm-start가 정규화 공간을 가로지르며, 이는 §5의 "전 n-grid 단계 동결" 조항 위반이다.

| 항목 | E3 배치 | E5 스트림 |
|---|---|---|
| 정규화 통계 (n=10↔80 / n=20↔80, l2 상대차) | **정확히 0** (동결) | action_mean 0.008962, proprio_std 0.048667 |
| n=80 도달 누적 학습 스텝 | 28,000 | 16,000 |
| n=80 최종 L1 | 0.0570 | 0.0718 |
| BC 풀 고유 base (80개 중) | 40/40 (분산 0.0) | 34/40 (최대중복 4, 분산 1.052) |

**(a) BC 풀 다양성**: 차이 있음 — 스트림 BC 풀은 초기상태 다양성이 낮고 중복이 크다. 스트림 base_idx는 (전역 인덱스) % 40이라 클러스터 노출이 셔플로 흩어지면 클러스터별로 불균등해진다.

**(b) 평가 대역**: 차이 있음 — 단 **스트림 probe가 더 쉬운 방향**이다. probe는 수집 대역(0–39) 재사용이라 BC 풀과 base가 0.85 겹치지만 E3 held-out은 전용 대역(40–49)으로 미노출이다 — **더 쉬운 평가에서 더 낮은 성적**이 나왔으므로 (b)는 간극을 설명하지 못하고 오히려 키운다.

**단서**: 정규화 이동은 성숙에 **성공한** 클러스터에도 동일하게 존재한다 → 부적격의 유일 원인으로 단정할 수 없다.

## 6. 판정자 확인 요청 사항

**(1) 후반 r_V 정체의 해석.** 마지막 1,000 ep의 r_V 0.496 중 X(부적격) 0.358 + I(미성숙) 0.138. 모든 적격 클러스터가 성숙해도 습관 담당 상한은 0.5165다. 이 분해를 **사후 분해로 명시**해 보고하는 것이 맞는지 (판정 근거는 사전등록 단측 검정 단독).

**(2) 성숙 초기 취약성 — 신규 발견 등재 여부.** 강등 3건이 모두 동일 패턴이다: 발화 5회 중 1회 실패 → ACI τ 상향 → p가 1−δ 바로 아래로 (0.897, 0.877, 0.882) → 강등. 재초기화 c=0.25가 σ를 압축하므로 성숙 직후 구간이 구조적으로 취약하다. 1건만 재형성에 성공했다. 이를 **신규 발견으로 등재**할지.

**(3) R_max 소진 후 영구 정체.** X 10개는 라운드 1·2 모두 probe 미통과로 확정됐고, 강등 후 R_max가 소진된 클러스터는 BC 풀이 133까지 쌓여도 재학습이 불가능하다(§4h 결정 4의 의도된 귀결). 이 비용을 Discussion에 명시할지.

**(4) novel 주입 분리 보고.** 주입 400건(r_V 0.920 vs 정규 0.637)에서 1개 클러스터가 성숙에 도달했다(libero_spatial_task7). 별도 절로 보고할지.

**(5) seed 2·3 착수 여부** — 본 판독으로 설계 변경 없이 진행해도 되는지.
