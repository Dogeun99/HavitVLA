## 0b. 시간 회계 3장부 (결함1 반영 — §5 등재)

| 장부 | 포함 | 보고 위치 | 지연 주장 산입 |
|---|---|---|---|
| **운영 (operational)** | 스트림 에피소드가 실제 소비한 시간·호출 | **H4·F4의 유일 근거** | **포함** |

## 1. 상태 기계 명세 (렌즈 1·5)

### 1.1 클러스터 lifecycle (4상태, §4h)

| 상태 | 진입 조건 | 발화 | 𝒟_k 갱신 | 재학습 자격 |
|---|---|---|---|---|
| **U 미지** | 클러스터 첫 조우 | VLA | 생성만(카운터 0) | 없음 |
| **I 기지-미성숙** | ensure_cluster 후 A_mat=0 | VLA | teacher 결과 기록(A_mat 불산입) | n≥20/80 도달 시 트리거 |
| **M 기지-성숙** | probe 라운드 통과 (Pr(s≥τ\|사후) ≥ 1−δ) | **Habit** | fire 결과 산입 + ACI observe_fire | ACI τ 상향으로 M→I 강등 가능 |
| **X 부적격** | probe 2라운드 소진·미통과 | VLA 고정 | teacher 기록만 | 없음(영구) |

전이 규칙 (드라이버가 **매 에피소드 종료 후** 평가):
```
U --첫 조우--> I
I --(|B_k| = 20) & 재학습#1 & probe#1 통과--> M
I --(|B_k| = 80) & 재학습#2 & probe#2 통과--> M
I --probe 미통과 & r_k = R_max(2)--> X
M --ACI τ 상향으로 A_mat=0--> I   (재학습 자격 유지, r_k 승계)
X --(재도전 없음)--> X
```
- **재학습 트리거 = |B_k| = teacher 성공 궤적 수**(BC 풀 크기) — 노출 수 아님 (결정 3).
  **probe 궤적·발화(습관) 궤적은 B_k에 불입** — 이중 장부(§2.5) + BC 풀 위생(§4h).
- **강등 후 재학습 자격 = 유지, r_k 승계, R_max = 2 전역** (결정 4). 강등 후 재학습에서
  수행하는 probe도 **라운드를 소비**하므로 무한 재시도 루프가 구조적으로 차단된다.
  현 구현 정합 확인(실측): 라운드1 통과 → 발화 실패 누적으로 τ 0.896 강등 시 r_k=1 승계 →
  라운드2 미달 시 즉시 X 전이. `gates/two_stage.py` 변경 불요.
- A_mat 계수는 **probe + fire만** (teacher 불산입, §4h) — `gate_regression.py` t1이 고정.
- 재학습 직후 `reinit_after_retrain(c=0.25)` → probe 기록 → 성숙 판정 순서 고정.

### 1.2 에피소드 단위 절차 (단일 경로)

```
1. 스트림 생성기가 다음 spec 산출 (§2 대역)
2. 클러스터 배정 = 1층 지시어 정확 일치(task-id)
3. I₀ 실현: E0-6 3단 프로토콜 (seed → reset → set_init_state → settle)   [렌즈 1·2]
4. 그림자 관할: DINOv2→PCA→Mahalanobis 점수·판정 계산 후 **기록만**       [렌즈 5]
5. 발화 결정: state==M → habit / else → VLA  (관할 불개입)
6. 실행: execute_chunk_with_boundary 단일 경로                              [렌즈 3]
7. 성공 판정 → 장부 갱신 (source 태그 필수) + ACI(발화 시만) + 로그 1행
8. 발화 에피소드면 counterfactual 큐에 spec 적재 (§3)
9. 재학습 트리거 검사 → 해당 시 §4 일시정지 절차
```

## 2. 스트림 스펙 대역 (렌즈 6) — **신설 승인 (결정 1), §4b 등재**

기존 5대역(수집 0–39/held-out 40–49/novel/probe/연쇄)과 disjoint한 **스트림 대역**을 신설한다.
**base = 수집 대역(0–39) 재사용** — 배포 후 재발 상황의 모사이므로 의도된 선택이며,
**held-out 대역(40–49) 사용은 금지**(§4b held-out 미노출성 보존).

| 대역 | base_idx | seed | noise_seed | 비고 |
|---|---|---|---|---|
| 스트림 (seed s ∈ {0,1,2}) | 0–39 재사용 | 70000 + 10000·s + i | 6·10⁶ + 10⁶·s + i | i < 4000 |
| novel 주입 (Spatial-b) | 0–39 | 80000 + 10000·s + j | 7·10⁶ + 10⁶·s + j | 10% = 400/seed |
| counterfactual 재실행 | **원 spec 그대로** | (동일) | (동일) | 재실행이므로 신규 대역 아님 — uid 동일, 실행자만 teacher |

- base_idx 0–39 재사용 = **배포 재발 상황 모사**(결정 1) — held-out 미노출성도 동시 보존.
- 드라이버 기동 시 **6대역 전수 `assert_disjoint` 1회 강제** 후 시작 (실패 시 기동 거부).
- novel 주입(Spatial-b)은 **정상 lifecycle 편입**(결정 5) — U→I→M/X 전이 대상이며,
  에피소드 로그의 `is_novel_injection` 태그로 사후 분리 분석이 가능하도록 한다.

## 3. counterfactual 큐 관리 (§4h 기준선)

**목적**: 발화 에피소드의 반사실 = "같은 spec을 teacher가 했다면?" — 스펙 단위 paired 비교.

| 항목 | 설계 | 근거 |
|---|---|---|
| 적재 | 발화(habit 실행) 에피소드의 spec + 결과 | §4h |
| 실행 시점 | **스트림 종료 후 배치** (스트림 중 실행 금지) — 결정 2 승인 | teacher 로드가 VRAM·시간 교란 + **스트림 중 실행은 H4 측정 대상(호출률·성공률) 자체를 오염** (판정 보강 근거) |
| 선행 관문 | **결정성 사전 검증: 발화 스펙 5–10개 × 2회 재실행 결과 일치** — 불일치 시 정지·보고 | 결정 2 |
| 실행자 | teacher(OFT), 동일 spec·동일 실행기 | 렌즈 3 |
| 결정성 사전 검증 | 본 실행 전 **표본 5 spec을 teacher 2회 재실행해 결과 일치 확인** (불일치 시 정지·보고) | §4h 명시 |
| 큐 크기 상한 | 없음(전량) — 예상 최악 3,600/seed | 아래 예산 |
| 산출 | `results/e5/cf_{seed}.jsonl` (spec uid, habit 결과, teacher 결과) | 렌즈 4 |
| 검정 | McNemar(불일치 쌍) + paired bootstrap 95% CI, margin −3%p | §2 |

**비발화 에피소드**: VLA가 실제 실행했으므로 그 자체가 기준선 관측 — 재실행 불요.
따라서 시스템 성공률 = 전 에피소드 실측, 기준선 성공률 = (비발화 실측) ∪ (발화 spec의 teacher 재실행).

## 4. 재학습·probe 일시정지/재개 프로토콜 (렌즈 1·2·4)

```
[일시정지]
 P1. 스트림 인덱스 t에서 트리거 감지 → 현 에피소드 완료 후 정지 (에피소드 중단 금지)
 P2. 스트림 상태 스냅샷 저장: {t, 클러스터별 상태·장부·BC 풀 크기·ACI 카운터, RNG 위치}
 P3. wall-clock 타이머 분리 시작 (학습 시간은 스트림 시간에 불산입 — §4h 회계)
[재학습]
 T1. BC 풀 = 해당 클러스터의 **teacher 성공 궤적만** (probe·habit 궤적 불입 — §4h 위생)
 T2. n-grid 단일 지점 학습 (lazy: 20 또는 80), warm-start 규율은 E2/E3와 동일
 T3. 체크포인트 경로: checkpoints/e5_s{seed}/{cluster}/act_n{n}_v{version}.pt  [렌즈 4 — 덮어쓰기 금지]
[probe]
 R1. reinit_after_retrain(c=0.25) 선행 → 그 사후 위에 probe 결과 누적
 R2. probe spec = §4b probe 대역(라운드별 분리), P=20, **오프-스트림**
 R3. 실행자 = 신 체크포인트 habit, 실행기는 동일 헬퍼
 R4. 결과는 update(source="probe") — ACI·r_V 계정 제외 [렌즈 5]
 R5. 성숙 판정 = Pr(s≥τ|사후) ≥ 1−δ (고정 통과선 없음)
[재개]
 C1. env 재생성 + 스냅샷 복원 → 스트림 인덱스 t+1부터
 C2. 재개 첫 에피소드도 E0-6 3단 프로토콜 (컨트롤러 이월 차단) [렌즈 2]
 C3. 타이머 재개, 학습 wall-clock을 VLA-호출 등가로 각주 (앵커 ⑤ 2,137 호출/회)
```

**미결**: 재학습 중 GPU 동시성(ACT 학습 ~5GB + 이후 teacher 로드 16GB)은 순차 실행으로 회피.

(probe는 에피소드 수도 형성 장부에 계상) / counterfactual 재실행 = `evaluation`.
`summary_{seed}.json`은 3장부를 **별도 절로 분리 보고**하며, r_V·지연 감소 주장은
`operational` 집계만 사용한다.

부속 산출: `results/e5/summary_{seed}.json` (r_V 창 비교·비열등 검정·부적격 명세·probe 이력 전문).
**그림자 q 출처**: known held-out 50:50 재보정 절차(seed 0) 산출값 — 보정 half는 평가에 재사용 금지(§4h).

## 6. heartbeat 통합 (신규 인프라)

- plan phases: `stream(4000, 단가=에피소드 실측 5.4s)` / `retrain(≤44, 단가=181.8s)` /
  `probe(≤880, 5.4s)` / `counterfactual(가변, 5.4s)` — 단가는 **앵커 파일에서 프로그래밍 취득**.
- counterfactual은 총량 미지 → `units=null` (phase % 강등 + "ETA 불확실").
- `tools/with_heartbeat.sh`로 tmux 동반 기동, **seed 단위 완료 시 중간 요약 1회** 보고 규약.
- stall 감지(30분 무진전) = [PROGRESS-STALL] — 재학습 구간의 정상 무진전과 구분하기 위해
  재학습 시작/종료 마커를 로그에 남기고 heartbeat가 해당 구간을 phase로 인식하도록 pattern 지정.

**예산 (앵커 재산출 — 25 클러스터·가중 단가 5.62s)**:
**운영** 6.2h/seed + **형성** (재학습 ≤2.5h + probe ≤1.6h) + **평가** CF ≤5.6h
= 최악 ~16h/seed, **3 seed ≈ 47.9h** (구 22셀 44.7h). 장부별로 분리 보고한다.
**축소 불요 (결정 6)** — 대신 **seed 1 완주 → 중간 판독(요약·이상 점검) → seed 2·3 순차**로

## 9. 본실행 전 스모크 관문 (신설 — 연구원 지시 2026-08-16)
